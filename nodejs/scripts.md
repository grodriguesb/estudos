======== scripts - package.json ========
Os scripts no package.json são comandos personalizados que pode ser executado usando o npm.

Eles ficam dentro da propriedade "scripts" e servem para automatizar tarefas como iniciar o projeto, rodar o servidor, executar testes ou buildar a aplicação.
=============================

======== npm run ========
O comando npm run nome-do-script é usado para executar um script definido dentro da seção "scripts" no package.json.
=============================
